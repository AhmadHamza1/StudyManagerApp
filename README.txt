StudyManagerApp

How to open:
1. Open Android Studio.
2. Choose Open.
3. Select the StudyManagerApp folder.
4. Let Gradle sync.
5. Run the app on emulator or device.

Project idea:
- MainActivity: choose a subject or add a custom subject.
- SubjectActivity: view explanation and enter quiz, assignment, and final exam marks.
- ResultActivity: display total grade and pass/fail.
